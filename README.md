# Sahil Ajay Pandey — Portfolio Website

A modern, responsive, dependency-free personal portfolio for semiconductor/electronics research, internships, thesis applications and general professional use.

## Files

- `index.html` — all page content and sections
- `styles.css` — visual design and responsive layout
- `script.js` — navigation, scroll reveal, reading progress and skill filtering
- `assets/favicon.svg` — favicon

## Optional: add your CV

Put your PDF in `assets/` as:

`Sahil_Ajay_Pandey_CV.pdf`

Then add a button in `index.html` such as:

```html
<a class="btn btn-primary" href="assets/Sahil_Ajay_Pandey_CV.pdf" target="_blank">View CV ↗</a>
```

## Deploy

### GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder.
3. Enable GitHub Pages from repository settings.

### Netlify / Vercel
Upload the folder as a static site. No build command is required.

## Personal edits

Search `index.html` for your contact details and replace them if needed. The website is intentionally static so it can be attached to most applications and hosted almost anywhere.
